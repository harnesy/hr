# Concession plan

Concessions made one at a time, under pressure, tend to go to the other side for nothing. A plan made in advance decides what can be given, in which order, what each one should buy, and where giving stops. It also keeps price from being the only thing on the table.

**Route:** `negotiation-prep` → **concession-plan** → `objection-replies` → the user negotiates → after-talk note.

## When to use

- After the preparation file is written and the walk-away point is confirmed.
- When the other side asks for a concession and the user wants to know what to ask in return.
- Not for deciding on the user's behalf what to give: the user agrees to each item first.

## Inputs

- The preparation file (goals, alternative, walk-away point, own estimate).
- The list of items the user is willing to trade, and any the user will not.

## Steps

1. **List tradeable items:** price, scope, timing, length of term, payment terms, service levels, who carries which risk, volume, publicity.
2. **Value each item** for the user (what it costs to give) and, as an estimate, for the other side (what it is worth to them).
3. **Order the concessions:** low cost to the user and high value to them first.
4. **Pair each concession with an ask:** what the user requests in return, specific enough to say yes or no to.
5. **Look at risk:** moving a risk to the side that can manage it better is a trade, and usually changes the price.
6. **Mark the stopping point:** where the user stops conceding, tied to the walk-away point, and the signs that the deal is moving below it.
7. **Plan a pause:** the point at which the user asks for time to think or to check with someone.
8. **Add the after-talk note template:** what was agreed against each objective, what is still open, what needs a professional's look before signing.

## Rules

- **Only agreed items.** Nothing appears that the user has not agreed could be given.
- **Every concession has an ask.**
- **The walk-away point is not crossed** in the plan; crossing it in the talk is the user's decision, with the alternative in view.
- **Honest trades.** No invented costs, deadlines or competing offers.

## Checks before hand-over

- Every concession has a matching ask.
- The order respects the walk-away point.
- Only items the user agreed to offer are listed.
- The after-talk note template is attached.

## Artefacts

- `negotiation/<deal>/concessions.md`: items with values for both sides, ordered concessions with asks, stopping point and signs, pause point, after-talk note template.

## Hand-over

- **To `objection-replies`:** the likely pushback on each ask.
- **To the user:** the plan.
- **To the startup finance analyst or financial analyst:** items whose cost to the user needs a model.
